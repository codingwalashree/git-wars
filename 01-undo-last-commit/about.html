About Git Wars

Practice everyday Git workflows with a tiny website.

What You Will Learn

  • How commits form a history
  • How the staging area works
  • How to undo a local commit safely
  • How to revert a commit already pushed

Our Approach

Make a change, inspect the diff, commit it, and then examine what Git does.

You do not need a specific programming language to follow these examples.
